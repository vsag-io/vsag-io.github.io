Lite RaBitQ8：当前实现契约

更新于 2026-10-12，本文覆盖历史 NONE/反向邻接关闭实验描述。公开适配器源码是 src/lite/rabitq_backend.cpp。

已实现什么

开启 ENABLE_RABITQ_LITE_BACKEND=ON 后，可从非空 BruteForce 显式调用 BuildGraph(VectorStorage::RABITQ8, degree, ef)。degree 为 2–64，ef 不小于 degree。 训练检查维度/数量上限、有限输入和模型算术；失败保留原后端。 固定配置采用确定性中心/旋转、3bit 粗过滤码和 5bit 补充码，复用原生 SIMD traits/内核， 保留 Generic 回退及标量对照。它不是完整 Full RaBitQ，也不能还原精确 FP32 原始向量。

新增、真实改值、物理删除、过滤查询、单次预算、保存加载均已实现。 模型训练后保持固定，分布漂移可能降低量化和图质量；不承诺自动重训、质量感知预算、 精确 FP32 重排或后台重建。

公开维护策略：与源码逐项对应

适配器构造执行：

state_.ConfigureIncomingProtection(
    rabitq::IncomingProtection::CACHED, false, false, false, true);

参数依次是模式、protect_add、protect_remove、protect_add_displaced、protect_link。 Build 和 Load 均启用反向邻接。因此 Update 保护、入度缓存、安全连接裁边已启用； 额外三个阶段 guard 未启用。这是公开适配器内部固定策略，不是用户配置选项。 安全裁边在存在其他安全可删边时保留目标最后一条入边；其回退不能保证全局连通或召回。

反向槽位经检查后使用 uint32。事务日志记录修改的编码/ID/出入边行及有效入度计数； 冷状态或未支持的内部状态仍可能回退复制。成本取决于访问/局部影响行、度数、入度、扩容和回退， 不能宣称 CRUD 恒定时间。Update 一次准备归一化查询/编码，并比较完整表示和全部元数据； 完全一致才跳过维护。编码相同不等于原始向量相同。失败恢复逻辑状态，但可能保留增长容量。 Remove bool 无法区分缺失 ID 和图分配失败。

查询、存储和持久化

保存模型、ID/映射、两组连续码平面、元数据、出入边邻接，不保存精确 FP32 矩阵。 查询变换、粗排路由、补充码精排和结果选择均有成本。查询求和/粗排内积缓存、Batch4 内核、 有界堆、大图访问位图和路由专用估计优化其中部分成本，不改变搜索预算。 距离是量化 L2 估计，过滤可能使结果少于 k。 普通有限评分保留原 float 求值顺序。距离/下界的中间结果非有限时，用 double 重新计算 再转换，避免大向量自匹配等可表示结果因中间溢出变成 NaN。超出 float 范围的估计值 用有符号无穷大表示；NaN 评分在进入候选堆前拒绝。

Save 流式写模型/编码/ID/CSR 格式拓扑，不重建原向量。Load 不训练并恢复可修改状态， 包括删空后重新新增。VSAGLQ01 v1 独立于浮点 VSAGLT01 v1/v2/v3 和 Full 格式。 整数/浮点位字段小端，校验声明长度、有限元数据、ID、邻接、截断及尾部输入。 模型/编码配置变化必须明确处理格式兼容；无校验和、fsync、原子文件替换或同实例并发承诺。 残差半径保留真实非负范数，质心处为零；安全归一化分母不再替换几何半径。 合法有限查询在 k=0 或索引为空时，完成输入校验后直接返回，不执行变换。 范数修正保留 v1 字段布局，现有正范数快照仍可直接读取而不重新编码。 修正后的快照可能包含零残差范数，需要修正后的读取器，旧读取器可能拒绝。 加载旧快照不会修复之前被替换成一的半径；受影响数据应从原始向量重新构建。

测试对应与完善程度

rabitq_backend_test.cpp 覆盖接口生命周期、过滤/预算、加载后继续 CRUD、损坏输入、 固定模型编码、标量/SIMD 尾部、安全裁边缓存、入边槽位/边校验、有界堆和流式 I/O。 分配故障测试覆盖回滚，但不保证全部外部分配器/平台故障。 详见Lite 要求与测试对照。

RaBitQ 功能已实现，不等于质量/性能全部完善。GIST 维护召回和固定模型漂移仍有缺口。 现有 10k/100k 真实改值证据不能替代小时级交错读写、独立盲测或同质量 Full 对照。 提高 ef 是质量/成本权衡，不是补缺失功能，也不是普遍加速。 历史性能报告由实验验收 PR #2926 独立维护；历史 NONE/反向关闭实验不是当前生产配置， 不能把不同版本最好值拼为最新指标。
