VSAG文档

独立 VSAG Lite

本文是 PR #2904 的当前受支持契约，更新于 2026-10-12。历史实验说明不能覆盖当前行为。

构建、配置与安装

cmake -S lite -B build-lite -G Ninja -DCMAKE_BUILD_TYPE=Release -DENABLE_TESTS=ON
cmake --build build-lite -j2
ctest --test-dir build-lite --output-on-failure
cmake --install build-lite --prefix "$PWD/install-lite"

默认后端是 FP32 BruteForce。ENABLE_RABITQ_LITE_BACKEND 默认 OFF，显式添加 -DENABLE_RABITQ_LITE_BACKEND=ON 才编译 RaBitQ8。 ENABLE_COVERAGE=ON 对库和测试编译单元一起插桩。构建动态和静态 libvsag-lite， 安装后 CMake 消费方使用 find_package(vsag-lite CONFIG REQUIRED) 和 vsag::lite。 lite/example 提供安装消费示例；rabitq_example.cpp 演示可选后端生命周期。 Lite 不链接 Full 的 libvsag.so。

架构、保留和裁剪

公开 vsag::lite::Index 拥有私有后端，默认连续存储 BruteForce 做精确平方 L2 查询。 显式 BuildGraph 在发布前构建替代单层图；它不是 Full HGraph/LazyHGraph，也不按数量自动切图。 输入保持 FP32，可显式选择 FP16 图或可选 RaBitQ8。未提供 SQ8、mmap、稀疏向量、语言绑定、 完整 Full 工厂或自动后端选择。

浮点存储使用连续向量/ID 数组、外部 ID 到槽位映射、出边和入边邻接。 删除把最后一个槽搬进空洞并修复引用；容量可能保留，不承诺把全部闲置内存归还操作系统。 局部事务日志备份修改的行/记录；失败后可能保留扩大的容量，但逻辑状态保持不变。 FP16 Save 直接借用已保存的半精度行，不再解码后重新编码。

RaBitQ 保存固定训练的中心/旋转模型、3bit 过滤码、5bit 补充码、每条元数据、ID 和图， 不保留精确 FP32 原始矩阵。当前公开构建/加载启用 32 位反向邻接和 CACHED 入度保护， 并启用安全连接裁边；额外 Add/Remove/被挤出目标 guard 仍为 false。 CACHED 同时启用 Update 保护。若存在其他可安全删除边，就保护旧目标最后一条入边； 没有替代边时仍使用原最远边回退，不是全局连通或召回保证。 详见RaBitQ 设计。

兼容、持久化和失败边界

Lite 是独立 API，不是 Full Index 的 ABI 可替换实现。同一实例必须由调用方串行化， 不支持并发查询或读写混合并发。输入仅在调用期间借用，结果和持久状态由索引拥有。

FP32 BruteForce 使用 VSAGLT01 v1、FP32 图 v2、FP16 图 v3；可选 RaBitQ 独立使用 VSAGLQ01 v1，浮点旧格式不变。全部小端，不兼容 Full 快照。 RaBitQ Load 恢复模型/编码/拓扑，不重新训练，也不能还原精确输入向量。 Load 需要可定位输入流并验证长度及内容。Save 不提供校验和、fsync 或原子文件替换， 失败可能留下部分输出；需要持久原子替换时，调用方负责临时文件和替换。

Add/Update/Search/Save/Load 使用现有 tl::expected/Error。 各后端统一将过滤回调的分配/容量异常转换为 NO_ENOUGH_MEMORY，其他抛出值转换为 INTERNAL_ERROR，不误报为 FP16 查询范围错误。回调失败的查询不修改索引内容。 Save 将分配/容量异常转换为 NO_ENOUGH_MEMORY，流错误仍为 READ_ERROR； 这不保证失败输出完整，也不提供原子保存。 Remove 为 bool，false 无法区分 ID 缺失和图分配失败。失败回滚恢复逻辑状态，不恢复分配器容量。 完整存储表示相同的 Update 不改变图；RaBitQ 编码相同不代表原始向量相同。
